# matinnikoo.github.io

My personal site. Live at [matinnikoo.github.io](https://matinnikoo.github.io).

Plain HTML, CSS and JavaScript, no framework or build step. The charts are drawn on canvas by hand.

| Page | What it is |
|---|---|
| `index.html` | The main site, with the projects and the scroll story |
| `lab.html` | Experiment Lab, the browser version of [abkit](https://github.com/MatinNikoo/abkit) |
| `shutdowns.html` | The interactive side of [internet-shutdowns](https://github.com/MatinNikoo/internet-shutdowns) |
| `simulator.html` | The app breakout simulator from [play-store-analysis](https://github.com/MatinNikoo/play-store-analysis) |
| `resume.pdf` | My resume |
